# 离线网页游戏：五子棋（第一版）设计

**日期：** 2026-08-24  
**状态：** 已确认  
**范围：** 游戏大厅 + 第一款可玩的五子棋；跳棋仅占位

---

## 目标

做一个可在浏览器打开的静态网站：同一设备双人对弈、完全离线可玩。第一版上线五子棋；大厅里预留跳棋入口，标为即将推出。

成功标准：两人能在电脑或平板上打完一局 15×15 自由五子；刷新不丢当前局；安装/断网后仍能进入大厅和下棋。

---

## 已确认决策

| 项 | 选择 |
|---|---|
| 对战 | 同一设备双人轮流，无 AI、无联机 |
| 规则 | 15×15 自由五子，无禁手；五连及以上即胜 |
| 设备 | 电脑、平板为主（鼠标 + 点按） |
| 风格 | 传统木纹棋盘、黑白棋子 |
| 语言 | 中文界面 |
| 功能 | 落子、轮流、胜负、重开、悔棋、最后一手高亮、获胜连线、刷新恢复、PWA 离线 |

明确不做（第一版）：AI、联机、禁手、计时、音效、跳棋玩法、「发现新版本」提示。

---

## 技术选型

**Vite + React + TypeScript + vite-plugin-pwa。**

纯静态站点，无后端、无账号。后续加跳棋时，大厅加一张卡片、再加一个路由即可。

备选曾考虑 Vue 3（能力相当）和纯 HTML（第一版更快，多游戏与离线缓存更难维护）。不采用。

---

## 架构

三层分离：壳（路由与 PWA）、五子棋 UI、纯逻辑引擎。

```
首页（游戏列表）
    └── 五子棋页
            ├── 棋盘 UI（木纹、落子、高亮）
            ├── 对局逻辑（15×15、轮流、五连、悔棋）
            └── 本地存档（localStorage）
```

规则写成与 React 无关的纯函数/模块，便于单测。UI 只负责渲染和把点击转成动作。

## 页面与交互

### 大厅

- 两张卡片：五子棋可进入；跳棋灰色，文案「即将推出」。
- 文案中文。

### 五子棋页

- 顶栏：返回大厅；状态文案（「黑棋下」「白棋下」「黑棋胜」「白棋胜」）。
- 棋盘：15 路木纹；棋子落在**交叉点**（不是格子中心）。黑先白后。
- 点到空交叉点即落子；已有子或对局已结束则忽略，不弹窗。
- 交叉点命中范围略放大，方便手指；鼠标仍点交叉点。
- 最后一手用小标记（如红点）；五连用连线或高亮标出。
- `悔棋`：撤销一步并换回手；无子可悔时禁用。
- `重新开始`：清空棋盘，黑先。
- 刷新后恢复当前局（含已结束的胜负和连线），直到点重新开始。
- 电脑/平板横屏为主：棋盘居中偏大；状态和按钮在侧边，窄屏时可叠到底部。
- 无拖拽落子、无花哨动画；落子即时出现。

布局示意：

```
┌──────────────────────────────────────┐
│  ← 大厅          黑棋下               │
├───────────────┬──────────────────────┤
│               │  最后一手 · 红点     │
│    木纹棋盘    │  悔棋  重新开始      │
│    15 × 15    │                      │
│               │  （窄屏叠到底部）     │
└───────────────┴──────────────────────┘
```

## 数据与规则

UI 只读状态、只发动作（落子、悔棋、重开）。引擎持有：

- `board`：15×15，空 / 黑 / 白
- `turn`：当前手（黑先）
- `moves`：落子历史（悔棋、最后一手）
- `winner`：无 / 黑 / 白
- `winningLine`：构成连线的交叉点列表

落子：空点且未结束 → 落子 → 追加 `moves` → 以该点为中心查横、竖、两斜，同色连续 **≥ 5** 则结束并记录 `winningLine`，否则换手 → 写入 localStorage。

悔棋：弹出最后一步，清除胜负与连线，轮到被悔的一方。  
重开：空盘、黑先，并清除存档。

---

## 存档与容错

- 键名固定，例如 `gomoku-v1`，只存当前这一局。
- 刷新时读档还原。
- 格式不对、缺字段、棋盘不是 15×15：**丢弃存档，开新局**，不进错误页。
- 点到已有子、已结束、棋盘外：忽略。
- `localStorage` 写入失败（隐私模式、配额）：对局仍可继续，刷新可能丢失；不打断下棋。

PWA：首次联网缓存页面、脚本和棋盘资源；之后断网可进大厅和五子棋。缓存更新用插件默认策略，第一版不做更新提示。

## 测试

规则引擎用 **Vitest**。每个行为一条用例；实现前先有失败测试。

必测：

- 空盘、黑先；空点可下，有子不可下
- 结束后不可再下
- 横、竖、两斜五连即胜，并给出连线格子
- 四连不赢；六连及以上算赢
- 悔棋后棋子消失、换回手；胜局悔棋后可继续
- 无子时悔棋无效
- 重开回到空盘黑先
- 存档：完整对局可还原；损坏/缺字段视为新局

UI 不写大量组件单测。完成后浏览器人工验证：

- 电脑点击交叉点、最后一手、获胜连线
- 平板点按是否好点
- 刷新恢复；悔棋、重开
- 断网后仍能打开大厅和五子棋

不测：AI、联机、跳棋、多端同步。
